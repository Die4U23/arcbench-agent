# ArcBench Agent

本仓库用于完成 **CS3604** 课程项目：设计并实现一个能够在 ArcBench 上运行、评测和参与排行榜竞争的 Agent。

## 项目目标

- 实现课程要求的 Agent；
- 接入 ArcBench 的任务与评测流程；
- 持续改进 Agent 的推理与任务解决能力；
- 记录实验结果，并以 ArcBench 排行榜成绩验证改进效果。

## 当前状态

项目处于初始开发阶段，后续将逐步补充运行方式、系统设计、实验结果和排行榜成绩。

## 课程信息

- 课程：CS3604
- 项目：ArcBench Agent
- 仓库：`Die4U23/arcbench-agent`
