## 改动

- 入口明确接受文字模型 `deepseek-flash`、`deepseek-v4-flash`，视觉字段另接受平台公布的 `deepseek-v4-flash-vision-exp`。保留提供方模型名；未知型号和所有 Pro 型号在 HTTP 前拒绝。整组配置验证后再设置环境变量。
- 每个实现阶段预先提供有界文件清单。批量读在真实读取与权限检查后，仅替换模型上下文中仍保留的相同完整内容。单文件显式刷新不压缩；截断、压缩淘汰、外部修改和回滚不复用失效证据。复用记录省去的字符数，不伪称 token 或供应商命中率。
- 周期检查通过后立即交回控制器，移除额外两个自由修改回合。完整边界检查、候选保护、最终需求审核仍执行。完整检查失败返回待修复，不能以局部自测通过宣称验收。
- 保持验证脚本原顺序。只有精确的 `npm --prefix frontend|backend run build|test` 根包装命令，且同轮子检查已执行、输入指纹未变时才合并。额外参数、命令、pre/post 钩子、重复目标、未执行目标或指纹不可用都执行原命令。每次新的验证仍执行检查，不跨轮缓存。
- 共享已有的有界验证输入指纹实现，避免新增另一套不一致的失效规则。

未引入后续 Docker 网关代码，未修改 Runtime SDK、原需求、公开用例或生成网站。未提高 10M token / 250 请求上限。
